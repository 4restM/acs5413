In-Class Activity: Vibe Coding an Agriculture Management App (60 Minutes)

Course: Mobile App Development (Graduate Level)
Technology: React Native + SQLite + AI Coding Tools
Duration: 60 Minutes
Format: Teams of 2–3 Students

Activity Overview

In this exercise, you will act as a mobile development team hired to create an MVP (Minimum Viable Product) for a farm management application. The client has provided only a list of possible features but has not specified detailed requirements. Your first task is to determine what the users need and then use vibe coding techniques (AI-assisted development) to rapidly prototype the application.

Learning Objectives

  • Create requirements from a loosely defined problem.
  • Write effective prompts for AI-assisted software development.
  • Develop a React Native prototype using SQLite.
  • Design a mobile application with multiple interacting features.
  • Critically evaluate AI-generated code and design decisions.

Client Request

The farm owner would like a mobile application that helps manage day-to-day farm operations.

Mandatory Features

  1. Farm Map with Markers
    • Display the farm map
    • Allow users to place markers for fields, equipment, storage areas, etc.
  2. Inventory of Supplies
    • Manage farm supplies and quantities
    • Data must be stored locally

Additional Features (Choose at least 3)

  • Plant Rotation
  • Inventory Taken/Returned
  • Total Plants Planted
  • Money In/Out
  • Local Weather
  • Equipment Maintenance
  • Task Manager
  • Harvest Log
  • Spray and Fertilizer Records
  • Labor Tracking

Minimum Features Required: 5

Technical Constraints

  • Use React Native
  • Use SQLite for local storage
  • Be designed for offline use
  • Use AI tools (ChatGPT, Copilot, Claude, Cursor, Windsurf, etc.)

Activity Tasks (60 Minutes)

Part 1: Requirements Discovery (15 Minutes)

As a team:

  • Identify at least 3 stakeholders.
  • Create at least 5 user stories.
  • Select the 2 mandatory features and at least 3 additional features.

Part 2: Vibe Coding Design (10 Minutes)

  • Design at least 4 screens.
  • Create a simple SQLite schema for your application.

Part 3: AI-Assisted Prototype Development (25 Minutes)

Use AI to generate code for:

  • React Native navigation structure
  • SQLite database setup
  • Farm Map screen
  • Inventory screen
  • One additional feature screen

Part 4: Team Reflection (10 Minutes)

  1. What prompts produced the best results?
  2. What code generated by AI was useful?
  3. What code required modification?
  4. What requirements did your team define?
  5. What are the strengths and weaknesses of vibe coding?

Example AI Prompts

Requirements Prompt:
You are a business analyst. Generate functional requirements and user stories for an agriculture management mobile application with farm mapping, inventory management, task tracking, and harvest logging.

Database Prompt:
Design a SQLite database schema for a React Native farm management app containing inventory, map markers, tasks, and harvest tracking.

React Native Prompt:
Generate React Native Expo code with SQLite and React Navigation for an agriculture management application containing Dashboard, Map, Inventory, and Task Manager screens.

Deliverable

  1. Selected features
  2. Stakeholders
  3. User stories
  4. Simple screen design/wireframe
  5. SQLite schema
  6. Sample AI prompts used
  7. Screenshots of generated prototype/code
  8. Reflection (1–2 paragraphs)

Evaluation (100 Points)

  • Requirements Quality – 20
  • User Stories – 15
  • Feature Selection & Justification – 15
  • SQLite Design – 15
  • Prototype Design – 20
  • Effective Use of AI/Vibe Coding – 10
  • Reflection – 5

Challenge Bonus (+5)

Create a convincing prompt that generates a complete React Native screen with SQLite CRUD functionality and explain why the prompt was effective.
